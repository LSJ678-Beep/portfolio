# 星际虫潮 · Interstellar Swarm

一款用 **Three.js** 编写的 3D 打怪升级射击小游戏，纯前端、零依赖、单文件逻辑，打开网页即可游玩。

🎮 **在线试玩：** https://lsj678-beep.github.io/interstellar-swarm/

## 玩法

- 用 **WASD** 移动，**鼠标左键**朝准星方向开枪（按住连射）
- **Shift / 空格** 冲刺闪避，**Esc** 暂停
- 消灭不断涌来的虫群获取经验，升级后从 3 张强化卡中三选一
- 强化可以叠加成流派：分裂枪管 + 爆裂核心、环绕光刃 + 吸血纳米、燃烧弹 + 低温弹……
- 每 5 波出现一只 **虫群首领（BOSS）**，会召唤小怪

## 内容

- **6 种敌人**：爬虫、跳虫、喷吐者、重甲虫、飞蝠、自爆虫，各自独立建模与行为
- **18 张强化卡**、补给箱、连杀加成
- **人形机甲主角**：头盔、胸甲核心、背包推进器、走路动画与开枪后坐力
- 半径 36 的可碰撞战场、掩体石柱、星空远景

## 本地运行

直接双击 `threejs-templates/游戏模板C-星际虫潮.html` 即可（三种加载方式：双击文件 / Live Server / 任意静态服务器都支持）。

## 目录

```
index.html                          入口页
threejs-templates/
  ├─ 游戏模板C-星际虫潮.html          游戏本体（单文件，约 109KB）
  └─ libs/three.global.js            Three.js r160 全局版
```

## 二次开发

游戏参数集中在文件顶部的三个中文配置区，改数值就能改手感：

| 配置 | 作用 |
| --- | --- |
| `SETTINGS` | 场地大小、玩家血量与移速、伤害、射速、冲刺冷却 |
| `ENEMY_TYPES` | 每种怪物的血量、速度、伤害、经验、造型尺寸 |
| `UPGRADES` | 全部强化卡的效果与稀有度 |

字体、模型全部由几何体实时生成，没有外部贴图与资源文件，方便课堂演示与魔改。
